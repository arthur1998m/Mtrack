# Android (Jetpack Compose)
## Instruções de Instalação e Uso
### Dependências Iniciais
- Jetpack Compose
- Material 3
- Outras dependências podem ser adicionadas no arquivo `build.gradle` conforme necessidade.

### Scripts Úteis
- Sincronizar projeto: `File > Sync Project with Gradle Files`
- Limpar build: `Build > Clean Project`
- Gerar APK: `Build > Build Bundle(s) / APK(s) > Build APK(s)`

---

> O arquivo `app/MainActivity.kt` já está criado como ponto de entrada inicial.
- Configurar estrutura de pacotes
